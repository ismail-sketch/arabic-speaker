# Arabic Speaker — голосовой тренажёр разговорного арабского

Тренажёр для практики **литературного арабского (фусха)**: вы говорите в микрофон,
тренажёр понимает речь, отвечает голосом и показывает текст, перевод и исправление ошибок.

## Возможности

- 🎤 **Распознавание речи** — в Chrome/Edge встроенное (Web Speech API), бесплатно и мгновенно.
- 🌐 **Любой браузер** — если браузер не умеет распознавать речь сам (Firefox, Safari),
  включается серверное распознавание: звук расшифровывается через AnyModel.
- 🔊 **Озвучка ответов** — встроенный арабский TTS браузера, бесплатно.
- 🧠 **Диалог** — любая модель через [AnyModel](https://anymodel.org) (OpenAI-совместимый API).
  По умолчанию `gc/gemini-2.5-flash` — быстрая, подходит для живого разговора.
- 📝 **Формат ответа**: арабская фраза → перевод на русский → разбор ошибок.
- 🧩 **Подробный разбор ошибок** по категориям: грамматика, лексика, порядок слов,
  предлоги, артикль, род/число/падеж — с пояснениями по-русски. Если всё верно — «✓ Отлично!».
- 🅰️ **Огласовки (харакаты) вкл/выкл** — переключатель в настройках и прямо в чате;
  выбор сохраняется. При выключении харакаты убираются даже если модель их добавила.
- 🗣 **Режим push-to-talk**: говорите в своём темпе, паузы не обрывают запись.
- ⌨️ **Горячие клавиши**: `Space` — 🎙 / отправить, `Esc` — остановить речь и запись.
- 🔁 **Повторить / 🐢 медленнее** у каждого ответа и **🎧 «Себя»** — записать свой вариант
  и сразу прослушать для сравнения с эталоном.
- 🔊 **Озвучка слова** — кнопка у каждого слова в итоге и словарике.
- 🛡 **Контроль распознавания** — если STT не уверен, текст не отправляется сразу,
  а попадает в поле ввода: исправьте опечатки и нажмите Enter. Тоже доступно кнопкой
  **«✎ Проверить»** и клавишей `Esc`. Модель отдельно предупреждена, что фразы приходят
  из распознавания речи, и не придирается к хамзе/та-марбуте/огласовкам.
- ⌨️ **Текстовый ввод** — резервный способ, если микрофон недоступен.
- 🇷🇺 **Смешанный режим (арабский + русский)** — если запнулись, спросите по-русски
  («как сказать…?»): тренажёр даст арабскую фразу, перевод и короткое пояснение.
  Язык микрофона переключается кнопкой «Язык: ар/рус» **прямо во время записи** —
  уже сказанное по-арабски сохраняется и отправляется вместе с русским вопросом.
- 🎭 **Темы-ситуации**: кафе, рынок, путешествия, работа, повседневная жизнь.
- 📈 **Уровни**: начинающий / средний / продвинутый (влияет на сложность и скорость речи).
- 📊 **Итог занятия** при «Завершить»: разбор ошибок (с повторами «×2»), фразы, о которых
  вы переспрашивали, и список слов. Кнопка **«Улучшить разбор ИИ»** даёт совет и точный
  список слов в JSON, а **«Скачать .md»** сохраняет итог файлом.
- 🗂 **История занятий и словарик** — последние 20 занятий и общие слова с переводом,
  счётчиком встреч и отметками «учу / знаю» (хранится в браузере, localStorage).

## Требования

- **Node.js** 18+ (используется встроенный `https`; внешних зависимостей нет).
- Браузер: **Chrome/Edge** — встроенное распознавание; **Firefox/Safari** — серверное
  (микрофон доступен только на `localhost` или по HTTPS).
- API-ключ **AnyModel** (OpenAI-совместимый шлюз).
- Для озвучки нужен арабский голос в системе (в Chrome/Edge на Windows он обычно есть).

## Установка и запуск

```bash
# 1. Скопируйте конфиг и вставьте свой ключ
cp .env.example .env
# откройте .env и заполните ANYMODEL_KEY

# 2. Запустите сервер
node server.js

# 3. Откройте в браузере
#    http://localhost:8787/
```

> Важно: открывайте именно `http://localhost:8787/`, а не файл `index.html` напрямую —
> при открытии файла браузер не сможет обратиться к локальному API-прокси.

## Настройки (`.env`)

| Переменная       | По умолчанию          | Описание                          |
|------------------|-----------------------|-----------------------------------|
| `ANYMODEL_KEY`   | —                     | API-ключ AnyModel (**обязателен**) |
| `ANYMODEL_BASE`  | `https://anymodel.org/v1` | Базовый URL API               |
| `MODEL`          | `gc/gemini-2.5-flash` | Модель для диалога                |
| `MODEL_TRANSCRIBE` | `gc/gemini-2.5-flash` | Модель распознавания речи (серверный режим) |
| `PORT`           | `8787`                | Порт локального сервера           |

Сравнение моделей по скорости ответа:

| Модель                | Ответ (примерно) |
|-----------------------|------------------|
| `gc/gemini-2.5-flash` | ~1 с ⚡          |
| `ag/gemini-2.5-flash` | ~2 с             |
| `glm/glm-5.3-flash`   | ~2.7 с           |
| `ds/deepseek-v4-flash`| ~6–9 с 🐢        |

## Как пользоваться

1. Нажмите **«Начать разговор»** — тренажёр поздоровается голосом.
2. Нажмите **🎙** (или `Space`) и говорите по-арабски, делая паузы.
3. Нажмите **«Готово»** (или 🎙 / `Space` ещё раз) — фраза отправится целиком.
   `Esc` останавливает озвучку и запись, не отправляя, и оставляет текст в поле ввода.
   Если распознавание не уверено, текст автоматически попадёт в поле для проверки:
   исправьте и нажмите Enter. Проверить вручную можно кнопкой **«✎ Проверить»**.
4. Ответ приходит текстом (арабский + перевод + исправление) и озвучивается.
   У ответа есть **🔁 Повторить**, **🐢 Медленнее** и **🎧 Себя** — записать свой вариант
   и прослушать. Слова в итоге и словарике озвучиваются кнопкой **🔊**.
5. Запнулись и не знаете фразу? Спросите по-русски: «как сказать „я хочу кофе“?» —
   тренажёр ответит по-арабски, переведёт и коротко объяснит. Голосом тоже можно:
   нажмите **«Язык: ар»**, чтобы переключить микрофон на русский.

### Смешанная фраза «на ходу»

Можно начать по-арабски, запнуться и, **не прерывая запись**, нажать «Язык: ар» →
«Язык: рус» и договорить по-русски. Сказанное не стирается: арабская и русская части
склеиваются в одно сообщение, и тренажёр отвечает на всю мысль целиком.
После отправки микрофон сам возвращается к языку, с которого вы начали.
Текст в поле ввода во время записи тоже дописывается к сказанному, а не отправляется отдельно.

### Если микрофон не работает в браузере

В настройках **«Распознавание речи»** выберите «Серверное» (или оставьте «Авто»).
В Firefox и Safari браузерного распознавания нет — «Авто» само включит серверное:
звук запишется, уйдёт на локальный сервер и расшифруется через AnyModel.
Микрофон должен быть доступен на `localhost` или по HTTPS (ограничение браузеров).

### Итог и история

6. Нажмите **«Завершить»** — откроется итог занятия: ошибки, трудные фразы, слова.
7. **«Улучшить разбор ИИ»** — модель добавит совет и точный список слов для повторения.
8. **«Скачать .md»** — итог с транскриптом сохранится файлом.
9. История занятий и общий словарик находятся на экране настроек; в словарике можно
   отмечать слова «учу / знаю» и видеть, сколько раз они встречались.

## Архитектура

```
Браузер (index.html)                Локальный сервер (server.js)         AnyModel
┌──────────────────────┐            ┌─────────────────────────┐          ┌──────────┐
│ Web Speech (STT)     │            │  /api/chat  (прокси)    │  HTTPS   │  LLM API │
│ PCM → WAV (STT)      │  POST /api/chat        → ключ .env → │ ───────► │          │
│ TTS (озвучка)        │  POST /api/transcribe  (аудио)       │ ───────► │  аудио   │
│ UI / история диалога │ ◄──────────│  статика index.html     │ ◄─────── │          │
└──────────────────────┘            └─────────────────────────┘          └──────────┘
```

Сервер нужен по трём причинам:
1. **Безопасность** — API-ключ хранится на сервере, а не в браузере.
2. **CORS** — браузер не может напрямую обращаться к большинству сторонних API.
3. **Любой браузер** — если у браузера нет своего распознавания, звук уходит на сервер
   и расшифровывается моделью (как и озвучка, ключ остаётся на сервере).

## Безопасность

- Ключ хранится в `.env`, который **исключён** из git (`.gitignore`).
- Сервер не раздаёт служебные файлы (`.env`, `server.js`, `package.json` и т.п.).
- Никогда не коммитьте `.env` и не публикуйте ключи.

## Данные

Итоги занятий и словарик хранятся локально в браузере (`localStorage`), последние 20 занятий.
Наружу уходят только запросы к модели через локальный прокси. В серверном режиме
распознавания запись (до 60 секунд) отправляется в AnyModel для расшифровки.
Очистка данных сайта удалит историю — для сохранности используйте «Скачать .md».
