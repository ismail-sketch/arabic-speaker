# Arabic Speaker — голосовой тренажёр разговорного арабского

Тренажёр для практики **литературного арабского (фусха)**: вы говорите в микрофон,
тренажёр понимает речь, отвечает голосом и показывает текст, перевод и исправление ошибок.

## Возможности

- 🎤 **Распознавание речи** — встроенное в браузер (Web Speech API), бесплатно, без ключей.
- 🔊 **Озвучка ответов** — встроенный арабский TTS браузера, бесплатно.
- 🧠 **Диалог** — любая модель через [AnyModel](https://anymodel.org) (OpenAI-совместимый API).
  По умолчанию `gc/gemini-2.5-flash` — быстрая, подходит для живого разговора.
- 📝 **Формат ответа**: арабская фраза → перевод на русский → разбор ошибок.
- 🧩 **Подробный разбор ошибок** по категориям: грамматика, лексика, порядок слов,
  предлоги, артикль, род/число/падеж — с пояснениями по-русски. Если всё верно — «✓ Отлично!».
- 🅰️ **Огласовки (харакаты) вкл/выкл** — переключатель в настройках и прямо в чате;
  выбор сохраняется. При выключении харакаты убираются даже если модель их добавила.
- 🗣 **Режим push-to-talk**: говорите в своём темпе, паузы не обрывают запись.
- ⌨️ **Текстовый ввод** — резервный способ, если микрофон недоступен.
- 🎭 **Темы-ситуации**: кафе, рынок, путешествия, работа, повседневная жизнь.
- 📈 **Уровни**: начинающий / средний / продвинутый (влияет на сложность и скорость речи).

## Требования

- **Node.js** 18+ (используется встроенный `https`; внешних зависимостей нет).
- Браузер **Chrome** или **Edge** (нужны Web Speech API: распознавание и синтез речи).
- API-ключ **AnyModel** (OpenAI-совместимый шлюз).

## Установка и запуск

```bash
# 1. Скопируйте конфиг и вставьте свой ключ
cp .env.example .env
# откройте .env и заполните ANYMODEL_KEY

# 2. Запустите сервер
node server.js

# 3. Откройте в браузере
#    http://localhost:8787/
```

> Важно: открывайте именно `http://localhost:8787/`, а не файл `index.html` напрямую —
> при открытии файла браузер не сможет обратиться к локальному API-прокси.

## Настройки (`.env`)

| Переменная       | По умолчанию          | Описание                          |
|------------------|-----------------------|-----------------------------------|
| `ANYMODEL_KEY`   | —                     | API-ключ AnyModel (**обязателен**) |
| `ANYMODEL_BASE`  | `https://anymodel.org/v1` | Базовый URL API               |
| `MODEL`          | `gc/gemini-2.5-flash` | Модель для диалога                |
| `PORT`           | `8787`                | Порт локального сервера           |

Сравнение моделей по скорости ответа:

| Модель                | Ответ (примерно) |
|-----------------------|------------------|
| `gc/gemini-2.5-flash` | ~1 с ⚡          |
| `ag/gemini-2.5-flash` | ~2 с             |
| `glm/glm-5.3-flash`   | ~2.7 с           |
| `ds/deepseek-v4-flash`| ~6–9 с 🐢        |

## Как пользоваться

1. Нажмите **«Начать разговор»** — тренажёр поздоровается голосом.
2. Нажмите **🎙** и говорите по-арабски, делая паузы.
3. Нажмите **«Готово»** (или 🎙 ещё раз) — фраза отправится целиком.
4. Ответ приходит текстом (арабский + перевод + исправление) и озвучивается.

## Архитектура

```
Браузер (index.html)                Локальный сервер (server.js)         AnyModel
┌──────────────────────┐            ┌─────────────────────────┐          ┌──────────┐
│ Web Speech (STT)     │            │  /api/chat  (прокси)    │  HTTPS   │  LLM API │
│ TTS (озвучка)        │  POST /api/chat  →  ключ из .env  →  │ ───────► │          │
│ UI / история диалога │ ◄──────────│  статика index.html     │ ◄─────── │          │
└──────────────────────┘            └─────────────────────────┘          └──────────┘
```

Сервер нужен по двум причинам:
1. **Безопасность** — API-ключ хранится на сервере, а не в браузере.
2. **CORS** — браузер не может напрямую обращаться к большинству сторонних API.

## Безопасность

- Ключ хранится в `.env`, который **исключён** из git (`.gitignore`).
- Сервер не раздаёт служебные файлы (`.env`, `server.js`, `package.json` и т.п.).
- Никогда не коммитьте `.env` и не публикуйте ключи.
