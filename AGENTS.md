# AGENTS.md — Arabic Speaker (тренажёр арабского в фусха)

Голосовой тренажёр разговорного **литературного арабского (MSA/фусха)**: пользователь говорит
в микрофон, приложение отвечает голосом и текстом, показывает перевод и исправляет ошибки.

## Стек и структура

- **Бэкенд:** `server.js` — Node.js (без зависимостей), локальный прокси к AnyModel
  (OpenAI-совместимый API) + раздача статики. Ключ в `.env` (не в git).
- **Фронтенд:** `index.html` — один файл: HTML + CSS + JS inline.
  STT и TTS — встроенные Web Speech API браузера (только Chrome/Edge).
- Слои: `index.html` (UI/речь) → `/api/chat` (server.js) → AnyModel.

## Запуск

```
cp .env.example .env   # вписать ANYMODEL_KEY
node server.js         # http://localhost:8787/
```

Модель по умолчанию `gc/gemini-2.5-flash` (быстрая, ~1 c). См. `server.js` (MODEL) и `.env.example`.

## Что уже сделано

- Голосовой диалог: STT `ar-SA/+fallback`, TTS, текстовый ввод.
- Push-to-talk: накопление всего распознанного (в т.ч. промежуточного), паузы не обрывают запись.
- Разбор ошибок по категориям (грамматика/лексика/предлоги и т.д.) + «✓ Отлично!».
- Переключатель огласовок (харакат) в настройках и в чате (сохранение в localStorage).
- Диагностика «Проверить микрофон», выбор голоса, уровень/тема, история диалога.
- Смешанный режим AR+RU: русский вопрос «как сказать…?» → арабская фраза, перевод и
  короткое пояснение; переключатель языка микрофона ар/рус (кнопка «Язык: ар/рус»).
- Смешанная фраза на ходу: язык можно переключать прямо во время записи — сказанное
  не теряется, а дописывается на другом языке в одно сообщение; после отправки язык
  возвращается к тому, с которого начали.
- Итог занятия при «Завершить»: ошибки из FIX, фразы, о которых переспрашивал, слова;
  кнопка «Улучшить разбор ИИ» (строгий JSON), экспорт в `.md`.
- История последних 20 занятий и общий словарик (localStorage) с отметками «учу/знаю»
  и счётчиком повторений.
- Git-репозиторий: https://github.com/ismail-sketch/arabic-speaker

## Технические заметки

- Ключ и служебные файлы НЕ отдаются браузеру (см. `serveStatic` blocklist).
- Формат ответа модели — метки `AR:` / `RU:` / `FIX:` (парсинг regex в `parseReply`).
- Русский вопрос в FIX не разбирается: модель считает его просьбой о помощи и оставляет FIX пустым.
- STT: `micLang` = `ar` | `ru` (localStorage `ar_miclang`), списки локалей `AR_LANGS` / `RU_LANGS`.
- Живое переключение: `switchLangLive()` делает `commitLocal()` → `engine.abort()` → новый
  движок с новой локалью; `base` сохраняется, `sessionStartLang` помнит исходный язык.
- Итог: `sessionEntries` → `finalizeSession()` (локально: FIX + русские вопросы) → ключ
  `ar_sessions` (до 20 занятий, транскрипт ≤120 реплик); слова сливаются в `ar_vocab`
  (ключ без огласовок и с нормализацией алифов/персидских букв).
- ИИ-разбор: `requestAiSummary()` просит строгий JSON и парсит `extractJson()`;
  проверка формы ответа и защита от кривых полей — в `requestAiSummary`.
- Харакаты: `stripHarakat` убирает диакритику `[\u064B-\u065F\u0670\u06D6-\u06ED]`.
- Сервер форсирует IPv4 и ретраи (обход `fetch failed` на Windows).

## Известные ограничения

- Web Speech API есть только в Chrome/Edge; арабская локаль поддерживается не везде
  (есть fallback-список языков и текстовый ввод).
- Распознавание одним движком = один язык: арабский и русский переключаются вручную,
  автоопределения языка речи нет (текстовый ввод понимает оба языка сразу).
- Оценка произношения отсутствует (исправляется только распознанный текст).
- Парсинг ответа regex-метками хрупкий.
- Итоги и словарик лежат только в браузере (localStorage): очистка данных сайта их удалит;
  хранятся последние 20 занятий, при нехватке места транскрипты отбрасываются.
- ИИ-разбор зависит от модели: если она вернёт не JSON, покажется ошибка и можно повторить.

## Следующие фичи (план, по приоритету)

1. **JSON-ответ модели** вместо меток AR/RU/FIX — надёжнее.
2. **Автоотправка по тишине** (порог ~4–5 с) + горячая клавиша.
3. **Повторение по словарику (SRS)**: карточки из `ar_vocab`, интервалы, «учу → знаю».
4. Режим «перевод» (RU → AR), потоковый ответ/перебивание.

## Конвенции

- Русскоязычные комментарии, ключ только через `.env`, без внешних зависимостей,
  UI-тексты на русском, арабский текст — без латиницы.
